# RenoFX

RenoFX is a package of ReShade effects for improving how games look on SDR and HDR displays. It helps you shape brightness, bring out highlights, refine color, and present the image comfortably on your screen.

> This README was written with AI assistance.

## What’s in the package

- **RenoFX HDR Toolkit** — the main effect for adjusting brightness, color, contrast, highlights, and HDR presentation.
- **SDR Compatibility Sandwich** — lets you use SDR-oriented ReShade effects while keeping an HDR presentation.

## Install

1. Install ReShade for your game.
2. Extract the repository to your reshade-shaders folder.

## Pick a starting point

The toolkit chooses an **SDR** or **HDR** menu based on the game’s display mode. It selects the matching controls automatically. For SDR games displayed on an SDR monitor, choose **RenoFX SDR Toolkit**. For HDR games, or SDR games you want to enhance for HDR, choose **RenoFX HDR Toolkit**.

### SDR game on an SDR display

Use the SDR Toolkit for straightforward color and contrast adjustments. Input and output are already set for the familiar sRGB image, so start with the **Color Grading** controls.

### SDR game on an HDR display

Open the HDR Toolkit and set **Input Transfer** to sRGB as a starting point. Set **Input Scaling** to the game’s paper-white brightness. Raise **HDR Boost** to brighten highlights, then adjust **HDR Boost Start** and **Ramp Intensity** to shape the smooth ramp. HAnS local highlight analysis is optional and off by default; enable it to get a gain map generated by analyzing the SDR source, which applies to HDR Boost. Principally similar to local tonemapping, which has problems but may subjectively be beneficial in some cases.

### HDR game on an HDR display

Open the HDR Toolkit and leave **Input Transfer** on Auto to begin. Match **Input Scaling** to the game’s brightness/paper white and **Input Peak Nits** to its peak brightness. Leave **Output Transfer** on Auto, then set **Game Brightness** and **Output Peak Nits** to suit your display.

## Adjust the image

- **Highlights**, **Shadows**, and **Contrast** shape the overall tonal balance. **Highlight Contrast** and **Shadow Contrast** give separate control over contrast in bright and dark areas.
- **Saturation** adjusts overall color. **Highlight Saturation** and **Blowout** shape color in bright areas.
- **Flare** lowers dark areas, and **White Point** warms or cools the image. **Mid Gray** sets the tonal pivot. A value of 50 is neutral for the grading sliders.
- **Tone Mapper** offers Neutwo and C-infinity Roll-off to smoothly bring highlights toward the selected output peak. Both use **Input Peak Nits** to identify the brightest expected source white.
- **Gamut Compression** helps keep colors within the selected display range. The toolkit targets BT.709 in SDR mode and BT.2020 in HDR mode.
- **SDR EOTF Emulation** adjusts the image’s HDR brightness response when needed.
- **Show Estimated Peak** displays an on-screen estimate of the image’s peak brightness.

Make a few adjustments at a time and use the neutral slider values as a reference when returning to the original look.

## Use SDR effects with HDR

Place the SDR Compatibility Sandwich around the SDR-oriented effects:

1. Enable **RenoFX SDR Compatibility Sandwich (Before)** before the effects.
2. Enable the SDR-oriented effects you want to use.
3. Enable **RenoFX SDR Compatibility Sandwich (After)** after them.

The pair prepares an SDR-compatible image for those effects, then restores the HDR presentation. Wide-gamut color preservation is enabled by default. To disable it, set the shader preprocessor definition `RENOFX_SDR_COMPATIBILITY_GAMUT_COMPRESSION` to `0`.

## Separate scene and UI brightness

This option lets RenoFX process the game scene before its UI is drawn, so **Game Brightness** and **UI Brightness** can use separate reference-white levels. It requires the [RenoDX Upgrade addon from the RenoDX repository](https://github.com/OopyDoopy/renodx/tree/main/src/addons/upgrade), ReShade addon support, and a compatible game/API.

1. Install `renodx-upgrade.addon64` from the RenoDX repository in a ReShade installation with addon support.
2. In the addon's **Swapchain Upgrade** settings, set **Output Format** to **scRGB (RGBA16F)**. Use scRGB for this workflow; HDR10 output format does not provide the floating-point scene/UI handoff needed for separate brightness control.
3. Enable **Shader Insertion → Enable Shader Insertion** in the RenoDX Upgrade addon, then restart the game as requested.
4. In RenoFX HDR Toolkit, enable **RenoDX Pipeline Insert → Use RenoDX Pipeline Insert**. The addon's insertion mode defaults to **Automatic**; if it inserts at the wrong point, use its overlay to configure a **Manual** insertion point for the game's scene output, before the UI draws.
5. Set **Game Brightness** for the scene reference white and **UI Brightness** for the UI reference white. The UI control is available when the HDR menu is active and does not affect SDR output.

If the addon cannot identify a safe insertion point, the pass may not run at the intended stage. You can compare the **Debug View → Split Intermediate** output with the swapchain image to check the inserted scene/UI handoff.

## RenoDX Upgrade addon

The [RenoDX Upgrade addon source](https://github.com/OopyDoopy/renodx/tree/main/src/addons/upgrade) provides swapchain upgrades, resource upgrades, shader insertion, and an optional **Device Proxy**.

- **Swapchain Upgrade → Output Format** upgrades the game's presentation swapchain to **scRGB (RGBA16F)** or **HDR10 (RGB10A2)**. Choose scRGB for RenoFX's separate scene/UI brightness workflow. The addon also offers resource upgrades for games that need extended-range render targets beyond the swapchain.
- **Shader Insertion → Enable Shader Insertion** enables the addon feature; restart the game after changing it. Insertion can run in Automatic mode or use Manual insertion points configured in the addon overlay.
- **Device Proxy** presents through a separate D3D11 device and swapchain when the game's rendering API cannot create the requested output directly. For a Direct3D 9 game that cannot use the requested HDR swapchain, install ReShade's DX9 addon support and try **Device Proxy** together with the scRGB swapchain upgrade. It is an optional compatibility path and should only be used with dx9 software.
